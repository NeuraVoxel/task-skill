# Quickstart: Canvas Circle

## Prerequisites

- A modern browser (Chrome, Firefox, Safari, or Edge).
- This repo checked out on branch `task/T-002` (or any branch that includes the change).

## Validate

1. Open `index.html` in the browser (double-click or `open index.html` on macOS).
2. Confirm:
   - Title is **Canvas Shapes**.
   - Blue rectangle is still present.
   - Large centered purple circle with darker outline is visible and overlaps the rectangle on top.

## Expected outcome

Both shapes visible on one canvas; no console errors required for success.
